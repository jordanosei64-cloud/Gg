# Snake — Tiny Arcade

A small, self-contained browser game built with HTML, CSS, and JavaScript.

## Play

Open `index.html` in a modern browser. No build tools or dependencies are required.

- Move with the arrow keys or **W A S D**.
- Press **Space** to pause or resume.
- On touch devices, use the on-screen direction pad.
- Eat fruit to grow and increase your score. Avoid the walls and your own tail.
- Your best score is saved in the browser.
